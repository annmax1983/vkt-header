01Overview

vkt-header is a browser extension for HTTP header modification during development and testing. All configuration — header rules, settings and licence state — is stored locally in your browser using chrome.storage.local. The extension contacts no server of ours except for optional licence activation and validation (see Third-Party Services below). Header rules, page content and browsing activity are never transmitted to us.

02Data Collection

vkt-header does NOT collect, transmit, or share any user data, with the single exception of license activation/validation described below. Specifically:

  • ❌ No browsing history is collected
  • ❌ No network request data is recorded
  • ❌ No analytics or telemetry
  • ❌ No cookies are read or written
  • ❌ No header rules, page content or browsing data are sent to any server

04Session Rules

vkt-header uses chrome.declarativeNetRequest.updateSessionRules() to modify HTTP request and response headers. These are session-level rules only:

  • Rules exist only during the current browser session
  • All rules are automatically cleared when the browser is closed
  • Enabled rules are re-applied automatically when the browser starts
  • No persistent network modifications are made

06Important Notes

  • This extension is intended solely for development and debugging purposes
  • Do not use this extension to bypass website security restrictions
  • Some HTTP headers are protected by the browser and cannot be modified (Host, Origin, etc.)
  • Header modifications apply only to the rules you create and enable.

07Third-Party Services

License key activation and validation communicate with api.annmax1983.com. The request contains only:

  • The license key you entered and the plugin identifier
  • A random install identifier generated locally on first activation — no device information is collected, hashed, or derived
  • Basic request metadata: browser name and major version, browser language, timezone, and user agent string

No header rules, no browsing history and no page content are ever transmitted. This request is made only when you activate a license or while a license is being re-validated; with no license activated, the extension makes no licence-server requests at all. Our license server records the IP address of these requests solely for rate limiting and abuse prevention — never for profiling, advertising, or sharing with third parties.

08Data Retention & Deletion

You can delete templates through the extension UI. Uninstalling the extension removes all stored data. Session rules are automatically cleared on browser restart.
