Privacy Policy

Effective date: August 2026

Overview

vkt-header is a browser extension for HTTP header modification during development and testing. All configuration is stored locally in your browser using chrome.storage.local. No data is uploaded to any server.

Data Collection

vkt-header does NOT collect, transmit, or share any user data. Specifically:

  • ❌ No browsing history is collected
  • ❌ No network request data is recorded
  • ❌ No analytics or telemetry
  • ❌ No cookies are read or written
  • ❌ No data is sent to any server

Data Storage

Storage KeyContent
vkh_templatesHeader snapshot templates (name, URL binding, header rules)
vkh_metaLicense status, premium flag

Session Rules

vkt-header uses chrome.declarativeNetRequest.updateSessionRules() to modify HTTP request headers. These are session-level rules only:

  • Rules exist only during the current browser session
  • All rules are automatically cleared when the browser is closed
  • Rules are isolated per tab — closing a tab removes its rules immediately
  • No persistent network modifications are made

Important Notes

  • This extension is intended solely for development and debugging purposes
  • Do not use this extension to bypass website security restrictions
  • Some HTTP headers are protected by the browser and cannot be modified (Host, Origin, etc.)
  • No header modifications are applied automatically — all changes require explicit user action

Third-Party Services

License key validation communicates with api.annmax1983.com. Only the license key, device hash, and plugin ID are sent. No header templates or browsing data are transmitted.

Data Deletion

You can delete templates through the extension UI. Uninstalling the extension removes all stored data. Session rules are automatically cleared on browser restart.
