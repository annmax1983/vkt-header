# vkt-header
[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

Chromium ブラウザ向けのグローバル HTTP リクエストヘッダー変更ツール。ルールは **ドメインのみ** でマッチ（大文字小文字を区別せず、パスは無視）し、**すべてのタブ** に適用されます — タブ分離やタブごとの状態はありません。

> Chromium · Manifest V3 · セッションルール · ドメインマッチング · グローバル

---

## コア機能：ドメインマッチング

各ルールに **Match URL** フィールドがありますが、使われるのは **ドメイン部分のみ** です：

- **大文字小文字を区別しない**（`EXAMPLE.COM` = `example.com`）
- パスは無視（`https://example.com/api` は `example.com` と同じ動作）
- 先頭の `www.` は省略可能 — `https://www.cnblogs.com/` と `https://cnblogs.com/` は同じルールにマッチ
- 他のサブドメイン（`pic.cnblogs.com`、`blog.cnblogs.com` など）はマッチ**しない**
- ルールはドメインが一致するすべてのリクエストに **すべてのタブで** 適用
- **Match URL が空** = ルールは **すべてのリクエスト** に適用

| 入力 | 実際のドメイン | 適用対象 |
|---|---|---|
| `example.com` | example.com | example.com へのすべてのリクエスト（任意パス） |
| `HTTPS://EXAMPLE.COM/api` | example.com | 同じ — パスは無視 |
| *(空)* | — | **すべてのリクエスト** |

サイドパネルの各ルールのスイッチで有効/無効を切り替えます。上部のメインスイッチで全ルールを停止/再開できます。

## 機能

| 機能 | 説明 |
|---|---|
| 🔧 **set / remove** | ヘッダーの上書き/追加と削除 |
| ✏️ **インライン編集** | サイドパネルで直接編集 |
| 📋 **ルールシステム** | 複数のヘッダー設定を保存 |
| 🌐 **ドメイン連携** | ルールをドメインにバインド（大文字小文字を区別せず、パス無視） |
| 🌍 **グローバルルール** | Match URL が空 → すべてのリクエストに適用 |
| 🏷️ **ドメインタグ** | 現在のドメインをクリックで自動入力 |
| 🔘 **ルールスイッチ** | 各ルールを個別に有効/無効化；メインスイッチで全停止 |
| 🔗 **すべてのタブ** | ルールはグローバル — タブ分離なし |
| 🧹 **セッションルール** | 再起動で消去され、起動時に自動再適用 |
| 📥📤 **インポート/エクスポート** | JSONバックアップ |
