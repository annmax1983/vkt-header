# vkt-header
[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

标签页隔离式 HTTP 请求头模拟修改工具 — 面向前端、QA 测试人员。

> 基于 Chromium · Manifest V3 · 会话规则 · 标签页隔离

---

## 核心差异化

| 竞品痛点 | vkt-header 解决方案 |
|---|---|
| ❌ 规则全局生效，切换网站依然篡改 | ✅ 严格绑定当前标签页，不影响其他页面 |
| ❌ 关闭标签页后规则残留 | ✅ 监听 tabs.onRemoved，自动清除 |
| ❌ 缺少快照/模板能力 | ✅ 保存多套 Header 快照模板，一键复用 |
| ❌ 数据上传、隐私风险 | ✅ 全部配置存储在浏览器本地 |
| ❌ 不知道哪些 Header 正在生效 | ✅ 状态栏实时显示当前激活模板 |

---

## 功能特性

| 功能 | 说明 |
|---|---|
| 🔧 **set / remove** | 支持覆盖/新增和移除请求头 |
| 📋 **快照模板** | 保存多套 Header 配置，一键切换 |
| 🔗 **URL 绑定** | 模板可绑定归一化 URL，打开页面自动提示 |
| 🧹 **会话规则** | 使用 declarativeNetRequest sessionRules，浏览器重启自动清除 |
| 🔒 **标签隔离** | 规则严格绑定 tabId，关闭标签自动撤销 |
| 🌍 **6 种语言** | 自动匹配浏览器语言 |

---

## 使用方法

1. 点击工具栏图标，侧边栏打开
2. 点击 **➕ 新建模板**，添加 Header 规则
3. 保存模板后，点击 **🚀 应用** 到当前标签页
4. 刷新页面让请求头修改生效
5. 关闭标签页或点击 **停止** 恢复原始请求头

---

## 隐私保护

- ✅ 全部配置存储在 `chrome.storage.local`
- ✅ 不上传任何数据到服务器
- ✅ 会话规则在浏览器重启后自动清除
- ✅ 不自动激活任何规则，全部由用户手动触发
- ✅ 仅用于开发调试，禁止用于绕过安全限制
