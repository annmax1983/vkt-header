# vkt-header
[English](../README.md) | [中文](README_zh.md) | Español | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

Modificador de cabeceras HTTP aislado por pestaña para navegadores Chromium.

> Chromium · Manifest V3 · Reglas de sesión · Aislamiento por pestaña

---

## Diferenciador

| Problema de la competencia | Solución vkt-header |
|---|---|
| ❌ Reglas globales | ✅ Aislado en pestaña actual |
| ❌ Reglas residuales | ✅ Limpieza automática al cerrar |
| ❌ Sin plantillas | ✅ Múltiples plantillas |
| ❌ Subida de datos | ✅ Todo local |

---

## Funciones

| Función | Descripción |
|---|---|
| 🔧 **set / remove** | Establecer o eliminar cabeceras |
| 📋 **Plantillas** | Guardar múltiples configuraciones |
| 🔗 **Vinculación URL** | Vincular plantillas a URLs |
| 🧹 **Reglas de sesión** | Se limpian al reiniciar |
| 🔒 **Aislamiento** | Estrictamente por tabId |
