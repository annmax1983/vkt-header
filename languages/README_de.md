# vkt-header
[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | Deutsch | [日本語](README_ja.md) | [Français](README_fr.md)

Tab-isolierter HTTP-Header-Modifier für Chromium-Browser.

> Chromium · Manifest V3 · Session-Regeln · Tab-Isolierung

---

## Vorteile

| Problem der Konkurrenz | vkt-header Lösung |
|---|---|
| ❌ Regeln gelten global | ✅ Streng isoliert auf aktuellen Tab |
| ❌ Regeln bleiben nach Tab-Schließen | ✅ Automatische Bereinigung |
| ❌ Keine Vorlagen | ✅ Mehrere Vorlagen speichern |
| ❌ Daten-Upload | ✅ Alles lokal gespeichert |

---

## Funktionen

| Funktion | Beschreibung |
|---|---|
| 🔧 **set / remove** | Header setzen/überschreiben oder entfernen |
| 📋 **Vorlagen** | Mehrere Header-Konfigurationen speichern |
| 🔗 **URL-Bindung** | Vorlagen an URL binden |
| 🧹 **Session-Regeln** | Beim Browser-Neustart gelöscht |
| 🔒 **Tab-Isolierung** | Streng an tabId gebunden |
