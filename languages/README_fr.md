## Différenciation

| Problème des concurrents | Solution vkt-header |
|---|---|
| ❌ Règles globales | ✅ Isolé sur l'onglet actuel |
| ❌ Règles résiduelles | ✅ Nettoyage automatique |
| ❌ Pas de modèles | ✅ Plusieurs modèles |
| ❌ Upload de données | ✅ Tout en local |

---

## Fonctionnalités

| Fonction | Description |
|---|---|
| 🔧 **set / remove** | Définir ou supprimer des en-têtes |
| 📋 **Modèles** | Sauvegarder plusieurs configurations |
| 🔗 **Liaison URL** | Lier des modèles à des URLs |
| 🧹 **Règles de session** | Effacées au redémarrage |
| 🔒 **Isolation** | Strictement par tabId |
