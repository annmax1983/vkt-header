Domain-Matched HTTP Header Modifier

VKT Header is an HTTP header modifier for Chrome and Edge that lets developers, testers and support teams change request and response headers without leaving the browser. Bind a rule to a domain, choose set, append or remove, and every matching request in every tab carries the change. Rules live in a side panel that stays open beside your work, so switching between endpoint debugging, mobile user-agent tests and referer checks takes seconds. No account, no ads, no tracking.

Everything it does

The core features at a glance.

01

Change request and response headers from one side panel, using set, append or remove for each header.

02

Match by domain only: letter case is ignored, paths are ignored, and a leading www. is optional.

03

Include subdomains with one switch, so example.com also covers app.example.com.

04

Global rules: leave the match field empty and the rule runs on every request.

05

Restrict a rule to a single HTTP method, or leave it open to all methods.

06

One-click presets for iPhone, Android, iPad, Googlebot, Referer and X-Forwarded-For.

Also included

  • Per-rule switches plus a master switch that stops or resumes every rule at once.
  • Request tester: paste any address to see which rules match, which headers would apply and which rule wins.
  • A toolbar badge shows how many rules are live.
  • Enabled rules re-apply themselves after a browser restart, so a working setup is not lost between sessions.
  • Import rules from ModHeader or Header Editor exports, with a clear report of anything that could not be carried over.

02

Free vs Premium

The free tier is a complete tool, not a trial. Premium is optional.

Free

up to 5 rules, up to 5 headers per rule, domain matching, subdomain matching, global rules, method filters, presets, the request tester, the toolbar badge and migration imports within the free allowance.

Premium

unlimited rules, unlimited headers per rule, and export and import of all your rules as a JSON file. One licence key activates on two browsers, and removing the licence from one browser frees that slot again.

No licence is needed to modify headers. Every free feature works without an account.

Private by design

Your data stays on your device. No account, no analytics, no tracking. Read exactly what is stored and when the extension uses the network.
